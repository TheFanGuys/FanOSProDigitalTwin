# FanOS Pro Digital Twin

3D model of the FanOS Pro control cabinet and full fan system, used as a sales and planning demo. Takes a few seconds to load on a phone.

**Open it:** https://thefanguys.github.io/FanOSProDigitalTwin/

Nothing you enter is stored in this repo.

Single-file app (index.html), no build step. Hosted on GitHub Pages. Upload a new index.html to update it.
